## Hiddify-Manager Deployment (Ansible)

This Ansible playbook installs and configures Hiddify-Manager on a selected virtual machine. It ensures a non-interactive setup and prints the panel access URLs after installation.

### Installation

1. Go to the **Doprax App Market**.
2. Select the **Hiddify-Manager** app.
3. Choose a **virtual machine** to deploy it on.
4. The playbook will run automatically and install Hiddify in non-GUI mode.

After installation, access details will be printed in the output.
